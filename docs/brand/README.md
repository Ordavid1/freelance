# Freelance Place logo

The selected logo is the ink geometric symbol on a yellow-green tile. It contains no wordmark or tagline.

![Freelance Place logo](../../public/freelance-place-logo.png)

## Assets

- `public/freelance-place-logo.svg`: scalable master, with an accessible title and description.
- `public/freelance-place-logo.png`: 512 × 512 raster export.

Both files contain the same approved design. The SVG is self-contained and requires no fonts or external resources.

## Usage

Use yellow-green `#CEEF00` for the tile and ink `#151719` for the symbol. Preserve the square aspect ratio, internal spacing, and rounded corners. Use `alt="Freelance Place"` when embedding the logo as an image.

The selected mark is used in the workspace, public pages, browser icon, and social preview.
